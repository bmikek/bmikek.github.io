Aquatic Safety Alert System

images/aquatic-safety-system.jpg

Project Overview

The Aquatic Safety Alert System is an embedded acoustic detection platform designed to assist lifeguards during emergency situations. The system automatically detects whistle signals and immediately transmits alerts across a wireless network for rapid response.

Built around an ESP32 microcontroller and INMP441 MEMS microphone, the device continuously performs real-time frequency analysis using Fast Fourier Transform (FFT) algorithms.

System Architecture

  • ESP32-WROVER microcontroller
  • INMP441 digital MEMS microphone
  • I2S audio acquisition
  • ESP-DSP optimized FFT processing
  • Wi-Fi based emergency notifications
  • Real-time monitoring dashboard

Key Engineering Features

  • 16 kHz audio sampling pipeline
  • 1024-sample FFT processing blocks
  • Dual-threshold whistle detection algorithm
  • Frequency-domain signal classification
  • Embedded web dashboard for alerts
  • Portable low-power deployment

Testing Results

Testing was conducted in simulated pool environments. The optimized 2200-3000 Hz detection configuration achieved:

  • 80% detection accuracy at 5 meters
  • 60% detection accuracy at 10 meters
  • 40% detection accuracy at 15 meters
  • Zero false positives during evaluation

Technologies Used

  • ESP32
  • C++
  • ESP-DSP
  • FFT Signal Processing
  • Embedded Systems
  • Wi-Fi Networking
  • I2S Audio
