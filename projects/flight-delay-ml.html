Flight Delay Analysis with Machine Learning

images/flight-delay-analysis.png

Project Overview

This project investigates whether flight arrival delays can be predicted using information available at booking time. A dataset containing approximately three million domestic flights from 2019 through 2023 was analyzed using supervised machine learning techniques.

The goal was to predict arrival delay duration in minutes using airline, airport, seasonal, and schedule-related features while avoiding information leakage from post-flight data.

Technical Contributions

  • Performed exploratory data analysis on 3 million flight records.
  • Applied cyclical encoding to month and departure hour features.
  • Implemented target encoding for airlines and origin airports.
  • Created interaction features capturing airline and time-of-day effects.
  • Built Linear Regression, Ridge, LASSO, Decision Tree, and Random Forest models.
  • Used feature engineering techniques including log transforms and outlier capping.

Results

The Random Forest model achieved the best performance, producing an RMSE of approximately 37.8 minutes. Feature importance analysis revealed that route distance, airline-time interactions, and airport historical delay behavior were stronger predictors than originally expected.
