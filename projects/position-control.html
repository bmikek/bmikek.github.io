DC Motor Position Control

Closed-Loop Control Lab · November 2025

Overview

This project explored closed-loop position control of a DC motor using negative unity feedback, proportional (P), and proportional–integral (PI) controllers implemented and tested in Simulink.

System Design

  • DC motor model with encoder-based position feedback
  • Unity feedback transfer function analysis
  • Error response evaluation using step, ramp, and sinusoidal inputs

Controller Comparison

  • Unity Feedback: Accurate for constant steps but failed for ramps and sinusoids
  • Proportional Control: Reduced oscillations with proper gain tuning but introduced steady-state error
  • PI Control: Improved ramp tracking but difficult to stabilize for sinusoidal inputs

Key Takeaways

  • Unity feedback is inadequate for dynamic position references
  • Proportional gain tuning balances noise and responsiveness
  • Integral action improves steady-state error at the cost of stability
