Rock–Paper–Scissors 1v1 Logic Decoder

Digital Systems Final Project · February 2024

Overview

This project implements a complete two‑player Rock–Paper–Scissors game using discrete digital logic. The system determines win, loss, or tie outcomes based purely on hardware‑level Boolean logic.

System Design

  • 6-player input signals (Rock, Paper, Scissors per player)
  • Combinational logic network for outcome detection
  • LED indicators for player choice and game result
  • Latching subsystem to hold inputs until reset

Logic & Validation

  • Derived Boolean equations for Player 1 Win, Player 2 Win, and Tie conditions
  • Constructed full truth tables to verify correctness
  • Implemented logic using AND/OR gate networks

Additional Features

  • Cheating detection for simultaneous multi-button presses
  • Buzzer and LED alerts for invalid input states
  • 3-bit decoder and latch system to preserve fairness
