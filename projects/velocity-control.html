DC Motor Velocity Control

Closed-Loop Control Lab · November 2025

Overview

This project focused on velocity control of a DC motor using increasing levels of controller complexity: unity feedback, proportional (P), PI, and PID control.

Controller Design

  • Laplace-domain motor modeling
  • Gain tuning through simulation-based experimentation
  • Evaluation using step and sinusoidal velocity references

Performance Results

  • P Control: Reduced noise but introduced consistent tracking error
  • PI Control: Near-zero steady-state error with smoother output
  • PID Control: Best overall performance with minimal lag and accurate amplitude tracking

Observations

  • Derivative action significantly reduced lag for sinusoidal inputs
  • PID control performed best for dynamic references
  • Over-tuning derivative gain increased noise sensitivity

Conclusion

PID control is recommended for applications requiring accurate velocity tracking of time-varying signals, while PI control offers a simpler compromise when noise is a concern.
