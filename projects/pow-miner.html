Project Overview

This project explores hardware acceleration through the implementation of a Proof-of-Work mining algorithm in both software and FPGA hardware.

The objective was to compare execution speed between a processor-based implementation running on a NEORV32 CPU and a custom hardware accelerator implemented in FPGA logic.

Hardware Design

  • Custom Proof-of-Work hash function
  • Finite State Machine architecture
  • IDLE, BUSY, and DONE operating states
  • Single-cycle hardware hash evaluation
  • Dedicated nonce search accelerator

Software Design

  • NEORV32 processor implementation
  • Sequential hash evaluation
  • Iterative nonce search loop
  • Software-based threshold comparison

Performance Results

The FPGA accelerator demonstrated dramatic improvements compared to software execution.

  • Easy Test: 233 cycles (software) vs 160 cycles (hardware)
  • Medium Test: 401 million cycles vs 4.3 million cycles
  • Hard Test: ~1 billion cycles vs 4.4 million cycles
  • Approximately 200× performance improvement
